# 🐦 Flappy Bird

A simple **Flappy Bird-style game** developed with **Python and Pygame**.

The project was created as a programming practice project to work with game loops, player movement, obstacles, collision detection, scoring, and basic game logic using Pygame.

---

## 🎮 About the Game

In this game, the player controls a bird that must pass through the gaps between pipes without colliding with them.

The objective is to survive as long as possible and achieve a higher score.

---

## ✨ Features

* 🐦 Player movement
* 🧱 Pipe obstacle generation
* 💥 Collision detection
* 🏆 Score system
* 🎮 Game over system
* 🔄 Continuous game loop
* 🔊 Game audio support

## ⚙️ Requirements

Before running the game, make sure you have:

* **Python 3**
* **Pygame**

You can check whether Python is installed by running:

```bash
python --version
```

or:

```bash
python3 --version
```

---

## 🚀 Installation

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

Then move into the project directory:

```bash
cd Flappy-Bird
```

### 2. Install Pygame

Install the required library using pip:

```bash
pip install pygame
```

If your system uses `python3`:

```bash
pip3 install pygame
```

---

## ▶️ Running the Game

After installing the requirements, run the main Python file:

```bash
python main.py
```

Or:

```bash
python3 main.py
```

The game window should open automatically.
